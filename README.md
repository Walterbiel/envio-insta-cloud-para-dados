# Cloud para Dados

Material gratuito do QG da Engenharia de Dados. Você recebeu porque comentou **CLOUD**.

## Como usar este material

1. Abra o arquivo [cloud-para-dados.pdf](cloud-para-dados.pdf) → clique em **Download** se quiser guardar
2. Use como mapa → achou um serviço numa vaga, procure o equivalente nas outras nuvens
3. Escolha uma nuvem para começar → veja a dica no último slide

## O que tem nos slides

→ Armazenamento e bancos nas 3 nuvens
→ Processamento e orquestração
→ Streaming, catálogo, segredos e BI
→ A arquitetura que se repete nas 3
→ Qual estudar primeiro

## Mapa rápido

| Bloco | AWS | Azure | GCP |
|---|---|---|---|
| Data lake | S3 | ADLS Gen2 | Cloud Storage |
| Data warehouse | Redshift | Synapse / Fabric | BigQuery |
| Spark | EMR / Glue | Databricks | Dataproc |
| Orquestração | MWAA | Data Factory | Composer |
| Streaming | Kinesis | Event Hubs | Pub/Sub |
